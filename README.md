# 🚀 AI Resume Ranking System

An AI-based web application that ranks multiple resumes based on a job description using NLP and Machine Learning.

## 🔥 Features
- Multi-resume upload
- Candidate ranking system
- TF-IDF + cosine similarity
- Keyword matching analysis
- Interactive dashboard (Chart.js)

## 🛠 Tech Stack
- Python (Flask)
- Machine Learning (Scikit-learn)
- HTML, CSS
- Chart.js

## 🚀 Run Locally
pip install -r requirements.txt  
python app.py

## 📊 Output
- Candidate scores
- Ranking system
- Visual dashboard chart
